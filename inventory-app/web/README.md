# لوحة تحكم الأدمن — Inventory Audit Web Dashboard

React + Vite + TypeScript + Tailwind. تتصل بنفس الـ backend API المستخدم من تطبيق الموبايل.

## الصفحات المطبقة
- تسجيل الدخول
- لوحة القيادة (إحصائيات + آخر مهام الجرد)
- مهام الجرد: إسناد مهمة جديدة بكل الخيارات (الجرد الأعمى، تجميع/تسلسل المواقع، نسبة إعادة العد)، توليد التقرير النهائي وتنزيله CSV
- الأصناف: عرض، استيراد CSV، استيراد مباشر من قاعدة بيانات خارجية
- المستودعات: عرض وإضافة مع المواقع الفرعية
- الموظفون: عرض وإضافة موظف مع تحديد نطاق الوصول لمستودعات محددة
- مواد قيد المراجعة: اعتماد أو رفض المواد غير المسجلة التي رُصدت أثناء الجرد

## التشغيل محلياً
```bash
cp .env.example .env   # عدّل VITE_API_BASE_URL إذا لزم
npm install
npm run dev
```

## النشر
```bash
docker build --build-arg VITE_API_BASE_URL=https://inventory-api.amrodev.com -t inventory-web .
docker run -p 8080:80 inventory-web
```
اربطها بنطاق فرعي (مثال: `inventory.amrodev.com`) عبر Cloudflare Tunnel كما فعلت مع [[amrodev-server]].

## غير مطبق بعد
- تعدد اللغات (i18n) والوضع الداكن — الواجهة حالياً عربية RTL فقط بثيم فاتح
- شاشة تفاصيل الصنف الفردي وتعديله
- تصفية/بحث في جداول الأصناف والمهام (تُعرض القوائم كاملة حالياً)
